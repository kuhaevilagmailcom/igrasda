МИШАНЯ 228 — СТАТИЧЕСКАЯ СБОРКА ДЛЯ ХОСТИНГА

Установка:
1. Распакуйте архив.
2. Загрузите ВСЁ содержимое папки mishanya228_hosting в корень сайта (например, public_html), заменив старые файлы.
3. Важно: замените и index.html, и src/three-game.js, и src/style.css, и папку vendor целиком. Не оставляйте файлы от старой версии.
4. На сайте выполните жёсткое обновление Ctrl+F5. Если панель ошибки осталась, откройте сайт в приватном окне.

Исправление ошибки querySelector:
В старых вариантах игрового модуля использовался элемент #signal, который убрали при переделке интерфейса. В index.html добавлен скрытый узел совместимости, а ссылка на three-game.js получила номер версии, чтобы браузер не использовал закешированный модуль. В актуальном игровом модуле этот узел не показывается и не раскрывает состояние аномалии.

Требования:
- обычный статический хостинг с поддержкой ES modules;
- HTTPS рекомендован;
- файлы .js должны отдаваться с MIME-типом application/javascript (для Apache правило есть в .htaccess).

Не требуется Node.js, npm, PHP, база данных или .bat.
